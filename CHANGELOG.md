# Changelog

## 0.1.0

- Installable library and parameterized notebook workflow for dataset preparation,
  zML training, OOF predictions, sigmaML training/calibration, and evaluation.
- Separate resumable Optuna searches, configurable features/objectives, and paired
  bootstrap intervals on saved predictions.
- Single-catalog diagnostics exported as PDF figures and CSV tables.
- Six frozen HSC-SSP PDR3 pipeline/layer bundles with verified manifests,
  independent applicability references, and sampled numerical validation.
- HSC recipes for reference bootstrap tables and search-pool sensitivity checks.
