# Single-catalog diagnostic inventory

Calculations live in turbopdz.evaluation.diagnostics, plotting helpers in
turbopdz.plotting, and report orchestration in turbopdz.analysis. All exported
figures are PDF; numerical tables are CSV. Category outputs.csv indexes record
saved files and reasons for optional omissions. No multi-catalog panels are
generated by this workflow; the HSC paper recipe remains separate.

Figures use native grids and explicitly declared mass/density conventions.
Displayed example/mean PDZs are normalized under that convention. The PCA
back-projection uses the fitted PDZ scaler (and whitening factor when applicable);
its stored sign is not assigned universal physical meaning.

## Scientific boundaries

- Point-estimate summaries use the calibration+test holdout; reliability results
  use the independent final test. Object IDs, not row position, align predictions.
- Paired point metrics share a finite mask. Within each controlled proxy or
  selector comparison, all methods share a common object mask and residual.
- Median bias is the median normalized residual, not its mean. Outlier values
  are fractions, not percentage points. Bin counts and empty bins are retained.
- AUC integrates against actual retained fractions; selector ties are retained.
- sigmaML importance propagates through the **frozen** calibration and reference
  CDF to rML, reporting scatter/outlier filtering AUCs alongside log-error MAE.
  zML importance reports its configured selection objective and redshift MAE.
- PCA tails use 20th/80th-percentile boundaries; ties can make the groups larger
  than 20 percent. Components are selected by absolute permutation impact.
- Calibration profiles use calibration-defined boundaries. Development curves
  are labeled OOF **training** diagnostics, not independent validation.
- Scaled-residual distributions and fractions within one scale are shape
  diagnostics, not Gaussian-coverage guarantees. Bootstrap intervals are
  conditional on saved models; permutation variability is not a bootstrap CI.
- Selector-debug plots expose catalog behavior without silently removing
  high-confidence outliers or refitting calibration after looking at the test.
- The optional population check requires explicit dataset-specific branch
  windows. It does not infer a spectral desert from histogram sparsity; empty
  overlap is reported without relaxing cells. Branch probabilities support both
  mass/density PDZs; native-bin two-peak smoothing is skipped on nonuniform grids.

## Report conventions

Numerical tables are CSV files. Related metrics share multi-panel PDF figures;
axes, bins, and output paths are configured per dataset and run.

Learning curves use the saved CV and final-fit histories. Models without those
histories have their corresponding plots explicitly skipped; diagnostics never
retrain a network to generate a curve. Calibration uses declared binning and
smoothing settings. Reports compare raw and calibrated profiles without an
additional parameter search or test-directed optimization.

Output indexes record optional omissions caused by missing photometry, disabled
PCA/importance, insufficient completed HPO trials, or empty selected cohorts.

For publication-quality bootstrap and population-bin comparisons, increase
sample sizes/resamples; tiny synthetic output is an execution check only.
